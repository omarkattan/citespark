Per-project model choice - 5 files, drag src/ and scripts/ to the repo root.

  src/db/schema.sql       projects.models JSONB (empty = default; run
                          npm run migrate after deploy)
  src/lib/dataforseo.js   resolveModel accepts a per-project override that
                          beats the env pin; askEngine threads it
  src/jobs/runCycle.js    resolves once per engine, writes a method note when
                          the model differs from last cycle, prices the
                          estimate from the chosen model
  src/server.js           PATCH /api/projects/:id/models; spend payload now
                          lists each engine's models with measured prices + tier
  src/public/app.js       model dropdown per engine in the cost panel, price
                          on every option, per-cycle delta in the toast

Verify after deploy, FRESH shell:
  npm run migrate
  grep -c "data-model-engine" src/public/app.js   -> 2 or more
